# Kema

La herramienta aliada para alcanzar tus metas. Kema permite el seguimiento de tus objetivos para que logres superar tus retos físicos y mentales, medir tu avance y mantenerte motivado.

## Stack

- Next.js 16 (App Router) + React 19
- Tailwind CSS 4
- shadcn/ui

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
